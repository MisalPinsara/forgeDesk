# forgeDesk

forgeDesk is a web-based Workshop Job & Document Management System for tracking companies, contacts, jobs, templates, and project files in one place.

## Features

- Manage companies and contact details
- Create, update, and track workshop jobs
- Organize engineers and buyers
- Upload and manage document templates
- Store supporting job files securely
- View dashboard summaries and job activity
- Secure user authentication

## Tech Stack

- React + TypeScript + Vite
- Next.js
- MongoDB Atlas
- Cloudflare R2
- Better Auth

## Getting Started

1. Clone the repository.

2. Install dependencies for both the client and server.

3. Configure environment variables for MongoDB, Better Auth, and Cloudflare R2.

4. Start the server and client development environments.
